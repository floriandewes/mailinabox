{% trans %}To use an alias or any address besides your own login username in outbound mail, the sending user must be included as a permitted sender for the alias.{% endtrans %}

{% trans %}Mail aliases API (advanced){% endtrans %}

{% trans %}Use your box’s mail aliases API to add and remove mail aliases from the command-line or custom services you build.{% endtrans %}

{% trans %}Usage:{% endtrans %}

curl -X VERB [-d "parameters"] --user {email}:{password} https://{{hostname}}/admin/mail/aliases[action]

{% trans %}Brackets denote an optional argument. Please note that the POST body parameters must be URL-encoded.{% endtrans %}

{% trans %}The email and password given to the --user option must be an administrative user on this system.{% endtrans %}

{% trans %}Verbs{% endtrans %}

{% trans %}Verb{% endtrans %} {% trans %}Action{% endtrans %}
GET{% trans %}(none){% endtrans %} {% trans %}Returns a list of existing mail aliases. Adding ?format=json to the URL will give JSON-encoded results.{% endtrans %}
POST/add {% trans %}Adds a new mail alias. Required POST-body parameters are address and forwards_to.{% endtrans %}
POST/remove {% trans %}Removes a mail alias. Required POST-body parameter is address.{% endtrans %}

{% trans %}Examples:{% endtrans %}

{% trans %}Try these examples. For simplicity the examples omit the --user me@mydomain.com:yourpassword command line argument which you must fill in with your email address and password.{% endtrans %}

# {% trans %}Gives a JSON-encoded list of all mail aliases{% endtrans %}
curl -X GET https://{{hostname}}/admin/mail/aliases?format=json

# {% trans %}Adds a new alias{% endtrans %}
curl -X POST -d "address=new_alias@mydomail.com" -d "forwards_to=my_email@mydomain.com" https://{{hostname}}/admin/mail/aliases/add

# {% trans %}Removes an alias{% endtrans %}
curl -X POST -d "address=new_alias@mydomail.com" https://{{hostname}}/admin/mail/aliases/remove
